1. 컴포넌트란? - 화면의 한 조각을 담당하는 재사용 가능한 UI 단위
2. 컴포넌트 작성 규칙
  - 이름은 대문자로 시작(필수)
  - 반드시 JSX로 반환
  - 최상위 요소는 하나만
  - props는 읽기 전용


            컴포넌트                  /           페이지           구분
파일명 :      자유                             반드시 page.js
역할 :     화면 조각, 다른 곳에서 가져다 씀       URL 주소가 있는 화면
위치 :     어디든 가능                          app/ 안의 폴도
접속 :     직접 접속 불가                       주소로 접속 가능


3. props란?
   부모 컴포넌트가 자식 컴포넌트에게 넘겨주는 값
4. export란?
   파일 안의 컴포넌트나 함수를 다른 파일에서 쓸 수 있게 내보내는 것
  import : 다른 파일에서 export 된 것을 가져오는 것

	                    default	                           /      named
export	export default function A(){}                       	export function A(){}
import	import A from './A'	                                  import { A } from './A'
파일당 개수	              1개	                                        여러 개
import 이름	            자유	                                  export 이름과 같아야 함
